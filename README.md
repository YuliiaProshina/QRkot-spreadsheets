# QRKot Spreadsheets

QRKot Spreadsheets — API-сервис для благотворительного фонда поддержки котов.

Приложение позволяет создавать благотворительные проекты, принимать пожертвования пользователей и автоматически распределять средства между открытыми проектами.

Также сервис умеет формировать Excel-отчёты по завершённым проектам и загружать их на Яндекс Диск.

## Возможности

- Регистрация и авторизация пользователей.
- JWT-аутентификация.
- Управление благотворительными проектами.
- Создание пожертвований.
- Автоматическое распределение пожертвований между проектами.
- Управление доступом суперпользователя.
- Формирование Excel-отчётов.
- Сортировка завершённых проектов по скорости сбора средств.
- Загрузка отчётов на Яндекс Диск.
- Получение публичной ссылки на созданный отчёт.
- Интерактивная документация Swagger.

## Установка

Клонируйте репозиторий и перейдите в директорию проекта:

```bash
git clone https://github.com/YuliiaProshina/QRkot-spreadsheets.git
cd QRkot-spreadsheets
```

Создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте его.

### Windows

```bash
venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Переменные окружения

Создайте в корне проекта файл `.env`.

Пример:

```env
APP_TITLE=QRKot
DATABASE_URL=sqlite+aiosqlite:///./fastapi.db
SECRET=your_secret_key
FIRST_SUPERUSER_EMAIL=admin@example.com
FIRST_SUPERUSER_PASSWORD=your_password
YANDEX_DISK_TOKEN=your_yandex_disk_token
```

Названия переменных должны соответствовать настройкам, определённым в проекте.

## Благотворительные проекты

Суперпользователь может создавать и изменять благотворительные проекты.

Проект содержит:

- название;
- описание;
- необходимую сумму;
- уже инвестированную сумму;
- дату создания;
- дату закрытия;
- статус завершения.

Когда необходимая сумма полностью собрана, проект автоматически закрывается.

## Пожертвования

Авторизованные пользователи могут создавать пожертвования.

Средства автоматически распределяются между открытыми благотворительными проектами в порядке их создания.

Если пожертвование больше суммы, необходимой текущему проекту, остаток переходит к следующему открытому проекту.

## Excel-отчёты

Суперпользователь может сформировать отчёт по завершённым благотворительным проектам.

В отчёт входят:

| Название проекта | Время сбора | Описание |
| --- | --- | --- |
| Название проекта | 5 ч. 20 мин. | Описание проекта |

Проекты сортируются по скорости сбора средств — от самых быстро закрытых к самым долгим.

В последней строке отчёта указывается общее количество проектов.

Время сбора отображается в формате:

```text
2 дн. 5 ч.
```

или:

```text
10 ч. 25 мин.
```

После формирования Excel-файл загружается в папку `Reports` на Яндекс Диске. Файл публикуется, а API возвращает публичную ссылку на него.

## Яндекс Диск

Для работы с Яндекс Диском необходимо получить OAuth-токен и указать его в `.env`:

```env
YANDEX_DISK_TOKEN=your_token
```

Приложение использует API Яндекс Диска для:

- создания папки для отчётов;
- получения URL для загрузки;
- загрузки Excel-файла;
- публикации файла;
- получения публичной ссылки.
